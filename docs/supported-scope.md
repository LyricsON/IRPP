# Périmètre

Version 1 accepte seulement un résident avec traitements et salaires, un montant annuel imposable déjà net de retenues sociales obligatoires, et les options explicitement modélisées. Aucun serveur, suivi ni transfert de données personnelles n’est utilisé. Les autres catégories de revenus, les situations d’assurance-vie et les cas familiaux non établis bloquent ou signalent une vérification au lieu de produire une déclaration supposée correcte.
